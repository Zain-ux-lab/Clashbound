# Shadow Theatre homepage

Published for review on 29 October 2026. The site root frontend/index.html loads the isolated styles, scripts and runtime assets in this folder. Run the normal FastAPI server and open /. Play now opens /battle.html; full roster opens /characters.html. No separate build step is needed.

Features: layered hero, fixed ground anchors with 2D puppet motion, section dust and mist, articulated bat atlas, illustrated Accord sparring sequence, original soundtrack, engraved buttons and a closing Blender film. Motion has pause and reduced-motion support; phones in portrait see landscape guidance. Audio begins after interaction and remembers mute preferences.

Scope: homepage presentation. Battle artwork, arenas, rules, bot and persistence are supplied by the existing game. The new Broken Accord arena concept is not bundled. The homepage combat-preview panel remains labelled Coming soon.

See CREDITS.md for media provenance and licences. Runtime assets only are bundled; local Blender projects, render-frame intermediates, WAV masters and inspection screenshots are excluded.
