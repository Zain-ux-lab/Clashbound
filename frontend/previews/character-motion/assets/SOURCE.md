# Preview artwork provenance

These are the previously approved Shadow Theatre character concepts made for Clashbound during the October 2026 design exploration. Character concepts and transparent derivatives were generated with OpenAI image generation, then trimmed for display. The sharp faceted style follows Zain and Abi's approved visual direction.

Drowned Belfry was exported as SVG from the project's Figma concept: https://www.figma.com/design/QGFLS4jDj3YJb20c8OudFo (arena node 6:2, scale guides and foreground hidden for the base export).

The effect geometry and cutout articulation are browser canvas code. This preview does not contain extracted Dicefolk or Darkest Dungeon assets, animations, or code. It includes no Blender renders or REA output.
